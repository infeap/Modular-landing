# Snabbguide: Lägg till screenshots

## Steg-för-steg:

### 1. Ta screenshots från Modular-appen

**Bild 1: `hem-oversikt.png`**
- Öppna Modular-appen
- Gå till Hem-vyn som visar översikten med modulkorten
- Tryck `Windows + Shift + S` för att ta screenshot
- Spara som `hem-oversikt.png`

**Bild 2: `dokumentmallar.png`**  
- Klicka på "Dokumentmallar" i appen
- Se till att visa kategorivyn (Ekonomi/Anbud, Projektering, etc.)
- Ta screenshot
- Spara som `dokumentmallar.png`

**Bild 3: `mappstruktur.png`**
- Klicka på "Mappstruktur" i appen  
- Ta screenshot av modulen
- Spara som `mappstruktur.png`

**Bild 4: `pomodoro.png`**
- Klicka på "Pomodoro" i appen
- Visa timer-vyn 
- Ta screenshot
- Spara som `pomodoro.png`

### 2. Placera bilderna

**Sätt 1: Via File Explorer**
```
1. Öppna File Explorer
2. Navigera till: C:\Users\nickl\Kodning\Duvero mallhub\mallhub-landing\public\screenshots\
3. Kopiera dina 4 bilder hit
4. Klart! ✅
```

**Sätt 2: Via Cursor**
```
1. I Cursor, högerklicka på "public/screenshots" mappen
2. Välj "Reveal in File Explorer"  
3. Kopiera dina 4 bilder hit
4. Klart! ✅
```

### 3. Kontrollera att det fungerar

Öppna terminalen och kör:
```bash
npm run dev
```

Gå till http://localhost:3000 och se dina screenshots på sidan! 🎉

## Förväntade filnamn:
- ✅ `hem-oversikt.png` (eller .jpg)
- ✅ `dokumentmallar.png` (eller .jpg)  
- ✅ `mappstruktur.png` (eller .jpg)
- ✅ `pomodoro.png` (eller .jpg)

## Tips:
- PNG ger bäst kvalitet för UI-screenshots
- Minst 1200px bredd rekommenderas
- Aspect ratio 16:9 fungerar bäst
